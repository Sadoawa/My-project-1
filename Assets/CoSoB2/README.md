# CoSoB2

Open `Scenes/CoSoB2_Preview.unity` and press Play. Use the five buttons in the top-left corner to select camera views. In Scene view, select the CoSoB2 instance and press F to frame it.

Editable model: `Prefabs/CoSoB2.prefab`. Separate groups contain the arcade building, courtyard-facing windows, garden/paving and corridor details.

This is a video-based study: 29.4 m frontage, 9 m depth, 3.9 m floor spacing and 7 bays are estimates. Three visible levels are represented; hidden elevations and their spatial arrangement are simplified. The B1 tower is not part of this B2 model.

See [reference observations and timestamps](../../Docs/CoSoB2/Reference.vi.md) for all assumptions and frame references. Audio was not used.

Use `UEH > CoSoB2 > Open preview scene` to open the saved scene. The `Build separate preview` menu also opens that scene when it already exists, without rebuilding or overwriting the model. Unity prompts to save any current scene changes before switching; Cancel keeps your current scene open. If only the prefab exists, the builder selects it and leaves it intact. Edit the saved prefab directly for further revisions.
